PORTFOLIO IRIE BI CHARLES - mode d'emploi
==========================================

OUVRIR LE SITE
  Dans VS Code : ouvrez le dossier, clic droit sur index.html > "Open with Live Server"
  (extension gratuite "Live Server"). Ou double-clic sur index.html.

OÙ MODIFIER QUOI
  js/config.js      -> votre e-mail, WhatsApp, LinkedIn
  js/data.js        -> vos projets et vos créations (ajouter = copier un bloc)
  css/base.css      -> couleurs et polices (variables en haut du fichier)
  css/sections.css  -> mise en page de chaque section
  index.html        -> les textes (À propos, services, savoir-faire...)

LOGO
  Déposez-le dans assets/logo/ sous le nom logo.png (ou changez le nom dans index.html).

SIGNATURE
  Dans index.html, cherchez id="trace-signature" : remplacez la valeur de d="..."
  par le tracé de votre signature SVG. Un seul endroit à changer.

IMAGES
  Déposez-les dans assets/images/ avec les noms indiqués dans js/data.js.
  Tant qu'une image manque, une zone colorée s'affiche à la place.

FORMULAIRE
  Sans réglage, le bouton Envoyer ouvre votre messagerie.
  Pour un envoi direct : créez un formulaire sur formspree.io et collez l'adresse
  dans js/config.js (ligne "formulaire").
